# Система предметов

Тест для Majestic. Только Node.js и TypeScript. Игроки получают предметы, используют их, выбрасывают и подбирают. Как и договаривались, реализация полностью своей головой, тесты сгенерил.

## Как запустить тесты

```bash
npm install
npm test
```

`npm test` сначала собирает проект, потом запускает сценарий из `test/items.test.ts`. В логе видно действия игроков, паузы между этапами и тики.

Мир без тестов запускается командой `npm start`, однако фактически никаких листенеров нет, поэтому передать команды в данный момент можно только через тесты.

## Как это устроено

Максимально упрощенная система. Index.ts собирает весь проект.

`core.service.ts` Ядро проекта, принимает команды и содержит бизнес логику: выдать предмет, использовать, выбросить, подобрать, сделать тик. Сделано только самое необходимое в рамках тестового задания, на прод такое выкатывать нельзя).

`storage.service.ts` Содержит эмулятор хранилища, держит игроков и предметы в памяти. 
Каждый запрос немного ждёт, чтобы было похоже на медленную базу.

Для упрощения разработки каждому предмету задал playerId и position, по ним и понимаю, что кому принадлежит, либо находится в мире.

`item.service.ts` Сервис для работы с предметами. Ищет и отдает нужный инстанс предмета. Реализация выполнена через наследование от базового объекта со стандартным набором обработчиков. Добавление новых типов предметов не требует корректировок кода если использовать в рамках обозначенной функциональности.

Конфиг лежит в `src/config/game.config.ts`: радиус, бонусы, сколько тиков предмет лежит на земле, сколько длится подсветка и тд.
